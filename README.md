# KEEPSAKE 2.0

Interactive editorial magazine prototype, independent from the original KEEPSAKE.

Live website: https://woodolll.github.io/keepsake-v2/

## Features

- Scroll-driven canvas, category filters, keyboard tooltips and drag selection.
- 70 categories, 67 question definitions, 30 analysis axes and five identity layers.
- First-question UI with browser-local storage.
- Two supplied magazine images displayed as complete visual mockups.

This buildless HTML/CSS/JavaScript prototype must be served over HTTP. The source is at the repository root. GitHub Pages publishes the main branch root for free.

Full questionnaire progression, actual AI analysis, image generation APIs, payments and QR sharing are not connected. Text and objects inside the supplied magazine images are not independently editable.
